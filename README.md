
# Pizza Ordering System (C#)

Ein einfaches Windows-Forms-Programm zur Pizza-Bestellung.

## Beschreibung

Dieses Projekt wurde mit C# und Windows Forms entwickelt, um ein Pizza-Bestellsystem zu simulieren.

Die Anwendung ermöglicht es dem Benutzer:

- Die Pizza-Größe auszuwählen
- Zutaten (Toppings) auszuwählen
- Den Teigtyp auszuwählen
- Zwischen „Eat In“ und „Take Out“ zu wählen
- Den Gesamtpreis automatisch zu berechnen

## Verwendete Technologien

- C#
- Windows Forms
- .NET Framework

## Funktionen

- Interaktive grafische Benutzeroberfläche
- Dynamische Preisberechnung
- Bestellübersicht
- Zurücksetzen der Bestellung
